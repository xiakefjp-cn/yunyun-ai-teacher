# 桌面版怎么用，已经检查过什么

电脑先安装Python 3.11或更新版本，并包含Tk窗口组件。双击项目里的 `start-desktop.cmd`，会出现一个输入教案目录的小窗口。

输入一个已经存在的教案文件夹，点“打开工作区并开始备课”。程序会用浏览器打开备课页面。这个版本的桌面使用方式就是“小窗口选目录，浏览器里备课”，没有另外制作安装包。

## 已经实际做过的检查

1. 在小窗口输入单独的测试目录，点击启动。
2. 用真实qwen-plus生成一节课，16项代码测试通过。
3. 故意删掉循环变量更新，运行失败，下载被阻止。
4. 恢复正确版本，逐项接受6项材料，查看文件改动并确认保存。
5. 到所选目录下，找到真正生成的 `published/lesson.md`，并下载教案压缩包。
6. 关闭小窗口，确认原来的本机服务停止。
7. 重新启动，输入同一个目录，确认历史、审核结果和文件都还在。

小窗口的输入、点击、关闭和重开是实际Windows窗口操作；浏览器里的步骤由自动化工具实际点击，并录成84秒视频。

本次用的是直接输入路径的方法，系统“选择文件夹”对话框还没测试。关闭启动器会停止服务，但不会删除教案；下次要继续时，请打开同一个目录。
