# 原生桌面启动链路验收

启动方式：Windows 安装 Python 3.11+（含 Tk），双击根目录 `start-desktop.cmd`。本版本的桌面形态为原生目录启动器加本机浏览器工作台。

实际验收：原生窗口输入独立老师目录，点击“打开工作区并开始备课”；真实 qwen-plus 生成；示例与分层参考解 16 条用例通过；人为删去循环更新触发失败并阻止下载；恢复旧修订，逐项接受6项；预览diff并确认写入；实际老师目录出现 `published/lesson.md`；下载ZIP。

随后用原生关闭按钮退出，确认旧服务停止；重新启动原生窗口并输入同一目录，点击打开；新的服务恢复已验证修订、全部6项审核、历史与本机文件。详见[验收证据](evidence/native-acceptance.json)。

原生窗口输入与启动/关闭/重开由 Windows UI 实际操作；浏览器工作台由 Playwright 实际操作并录制84秒视频。目录采用直接输入方式，未测试系统文件夹选择对话框；未宣称拥有独立嵌入式桌面WebView或安装包。
