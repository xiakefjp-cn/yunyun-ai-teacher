## 演示1：机器人重复前进

range(n)生成0至n-1，共n次；每次position增加10并打印，体现累计位置。n=0时range(0)为空，无循环。

```python
n = int(input())
position = 0
for i in range(n):
    position += 10
    print(position)
```

检查1：输入 '0'，应输出 ''
检查2：输入 '1'，应输出 '10'
检查3：输入 '3'，应输出 '10\n20\n30'

## 演示2：到达目标距离

初始化position=0；条件position<target保证未达目标才继续；每次+10更新位置；n=0时条件假，直接输出0。

```python
target = int(input())
position = 0
while position < target:
    position += 10
print(position)
```

检查1：输入 '0'，应输出 '0'
检查2：输入 '25'，应输出 '30'
检查3：输入 '10'，应输出 '10'
检查4：输入 '1'，应输出 '10'

## 基础：六边形指令序列

输入非负整数n（0~100），按行输出n次'移动10步'和'右转60度'（共2n行）。n=6对应六边形指令序列。

```python
n = int(input())
for i in range(n):
    print('移动10步')
    print('右转60度')
```

评分参考：循环范围正确4分；两行指令均在循环内4分；n=0无输出2分

检查1：输入 '0'，应输出 ''
检查2：输入 '1'，应输出 '移动10步\n右转60度'
检查3：输入 '6'，应输出 '移动10步\n右转60度\n移动10步\n右转60度\n移动10步\n右转60度\n移动10步\n右转60度\n移动10步\n右转60度\n移动10步\n右转60度'

## 进阶：逐桌清扫计数

输入要扫的桌子数n（0~100），用while模拟逐桌清扫过程，只输出最终扫过的桌子总数。

```python
n = int(input())
count = 0
while count < n:
    count += 1
print(count)
```

评分参考：初始化2分；终止条件与更新4分；避免死循环2分；n=0边界2分

检查1：输入 '0'，应输出 '0'
检查2：输入 '3'，应输出 '3'
检查3：输入 '1'，应输出 '1'
检查4：输入 '100'，应输出 '100'

## 挑战：首次达到目标次数

输入目标距离（0~100），每次移动10步，求首次达到或超过目标所需的最少次数。只输出次数。

```python
target = int(input())
count = 0
position = 0
while position < target:
    count += 1
    position += 10
print(count)
```

评分参考：循环条件3分；更新顺序3分；最小性逻辑2分；n=0零边界2分

检查1：输入 '0'，应输出 '0'
检查2：输入 '25'，应输出 '3'
检查3：输入 '10'，应输出 '1'
检查4：输入 '1'，应输出 '1'
检查5：输入 '30'，应输出 '3'
