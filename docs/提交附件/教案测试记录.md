# 用参考教案进行的实际测试

这次参考一份小学Scratch《循环结构》教案，测试本机版能否借用其中的活动，改成初二Python的40分钟课。原始Word先转成文本，去掉学生姓名后再交给真实qwen-plus。班情使用演示数据，不是真实学生记录。

## 第一轮没有达到要求

代码16项检查通过，但教案只在一段讲解里加了参考内容，示例和练习基本还是默认模板。所以不能因为代码通过就说改编成功。

## 第二轮重新编写

明确要求替换两个示例和三道练习，围绕机器人移动、扫地计数和六边形指令安排。模型提供的19项检查全部通过；另外编写的17项检查也全部通过，例如移动10次累计100步、目标25时停在30步、最少需要3次。两组检查有重叠，不是36种不同输入。

人工检查仍发现讲解变量名与代码不符，以及凭空增加“角度差30度算不同”的标准。提交的待审核教案已修正这些文字，代码没有改动；模型原稿另附，方便对照。
