# 设计与教育判断

这个项目先帮初二信息科技老师备一节《循环结构》课：给出40分钟教案、两个代码示例和三道不同难度的练习。目标是让老师少花时间整理材料，也能看清哪些地方需要自己把关。

**1. 怎样避免把错误带进课堂？**

AI写出的内容先当草稿。程序会真的运行示例和参考答案，对照输入、预期结果和实际结果；运行失败就不能导出。老师还要检查讲解对不对、题目难不难，再逐项点“接受”。保存前会展示文件改动，覆盖旧文件前先备份，生成和修改过程也有记录。但程序只能检查已写出的测试，不能保证教案每句话都对，教学判断仍由老师负责。

**2. 时间有限，哪些功能先不做？**

先不做学生端、多人账号、完整代码编辑器，也不对接学校系统。这些都需要时间，还会分散精力。我先把“提出需求→生成→运行检查→老师确认→保存教案”这一整套做通。班情也要影响安排：有人写死循环，就多练变量如何变化；有人没交作业，先了解原因，不能直接认定他不会。

**3. 怎样使用AI，出错后怎么改？**

开发时由Codex协助写代码和文档；产品中用qwen-plus生成教案。给AI的要求是：“给初二准备40分钟循环课，包含两个示例、三道分层题；每段代码给出测试输入和正确输出；针对3人写死循环安排讲解。”

真实问题是：教案只写“逐个检查边界”，老师不知道具体查什么。要求补充后，AI又把循环结束后的变量值讲错了，代码的16项测试却都通过。人工逐行对照代码，指出具体输入和正确结果，再让它改；另外补了3项检查。这个例子说明，运行成功也不能省掉老师审核。[完整经过](AI修正案例.md)

**4. 将来给学生用，怎样避免直接抄答案？**

先让学生写自己的尝试、预测输出或填变量表，再按他卡住的地方给一点提示。参考答案是否开放由老师决定；学生不能直接看到教师版答案。最后用一道换了情境的题，请学生解释做法，看看他是否理解。

**5. 真正进班级，第一步做什么？**

先请一位老师带一个班试用，逐题检查答案和讲解，并补充由老师单独编写的测试。收集“哪里看不懂、哪里不适合上课”，据此修改。只用全班人数这类汇总数据，不把姓名、学号、学生作业原文发给外部模型。上线前还要做好账号、不同老师资料的分开保存、代码运行限制和记录删除规则；涉及未成年人信息时，要先按学校要求处理授权和告知。
