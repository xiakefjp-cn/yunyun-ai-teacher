# 真实 AI 产出的发现与修正

本案例使用合成班情，不包含学生个人资料；原始教案来自此前真实 qwen-plus 调用。完整前后产物、反馈 prompt、模型返回标识和用量见 [证据 JSON](evidence/education-revision.json)，复现脚本为 `scripts/education-revision.py`（会调用付费 API）。

## 发现

原教案的“分层练习”只有“基础必做、进阶合作、挑战选做；逐个检查边界”，没有说明教师检查什么、学生交什么。人工审核要求模型补充问题、预期答案和补救动作。

模型补写后，代码仍然 16/16 用例通过，但教案出现两个真实错误：

- 基础题代码输出 2 到 n 的偶数，文字却把 n=1、2 写成单值、双值。实际上 n=0、1 无输出，n=2 只输出 2。
- 进阶题 `i=1`，每轮累加后 `i+=1`。模型将 n=0、1、5 退出时的 `(s,i)` 写成 `(0,0)、(1,1)、(15,5)`，正确应为 `(0,1)、(1,2)、(15,6)`。它混淆了当前循环值与退出状态。

## 修正

反馈明确指出上述输入、错误期望与正确状态，要求区分“进入本轮、更新后、退出时”，保留已有代码和用例、总课时 40 分钟。

第二轮真实模型返回已纠正这两处：基础题改为“空/空/单值”；进阶题列出正确终值和每轮更新后变量。重新真实执行仍为 16/16 通过，课时仍为 40 分钟。证据同时保留错误版，避免只展示最终结果。

## 边界

这是教案文字的真实错误，靠人工逐项对照代码发现；当前系统没有自动检查全部自然语言与代码的一致性。模型修订仍是草稿，例如示范段将示例变量 total 泛写成 s，教师应统一板书变量。教师确认承担教学内容与课堂适配判断，不能由“测试通过”替代。视频中的死循环另属人工故意注入实验，不冒充模型自然失败。
