# AI写错了什么，我怎么发现和修改

这次用的是qwen-plus真实生成的教案，班情是为演示编写的，没有真实学生资料。

## 一开始的问题：教案说得太空

分层练习只写了：“基础必做、进阶合作、挑战选做；逐个检查边界。”

老师看完还是不知道该问什么、检查什么。我要求AI补充具体问题、学生要写的东西、正确答案，以及答错后怎么教。

## 补写之后，又出现了具体错误

第一处：基础题要求输出2到n之间的偶数。输入1应该什么也不输出，输入2只输出2。AI却说输入1会输出一个值、输入2会输出两个值，显然没有对照题目的代码。

第二处：进阶题中，i从1开始，每次累加后再加1。AI把“最后一次参与累加的i”和“循环结束后的i”混在了一起。

|输入n|AI写的循环结束后i的值|对照代码后应有的值|
|---|---|---|
|0|0|1|
|1|1|2|
|5|5|6|

例如输入5，加完第5次后，i还会从5变成6，再判断6是否小于等于5。这时才退出，所以最后的i是6。

## 我怎么改

把错误直接指出来，而不是只说“再写好一点”：

> 基础题是输出偶数，输入0和1都没有输出，输入2只输出2。进阶题每轮最后还有i加1，所以输入0、1、5时，退出后的i分别是1、2、6。请改正教案，并说清记录的是进入循环时、更新后，还是退出时。保留已有代码、测试和40分钟课时。

第二轮真实回复已改正这两处，还列出了每轮更新后的变量值。我重新运行了原来的16项代码测试，又补了3项检查，专门核对退出时的值，全部通过。

## 这件事说明什么

当时程序的16项测试本来就全通过，错的是讲解文字。这个错误是人工逐行对照代码发现的，系统还不能自动检查教案里的每一句话。

修订后也仍需老师复核，例如示范段用了s来代指原示例中的total，上课板书前要把变量名统一。不能看到“通过”就直接拿去上课。
