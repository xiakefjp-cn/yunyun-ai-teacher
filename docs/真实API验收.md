最初两轮测试记录日期为2026年10月30日。使用了密钥对应的北京业务空间接口，密钥只留在本机 `.env`，没有上传仓库。

输入初二《循环结构》的备课需求，模型返回一份教案、两个示例和三道不同难度的练习。程序真的运行了代码，16项测试全部通过。

这两次都第一次返回就通过了程序检查，没有用到自动修复。后来另做的真实教案文字纠错见 [AI修正案例](AI修正案例.md)。
